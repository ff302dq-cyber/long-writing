# 长文写作助手

使用独立的写作模型提供商生成长文章，适合把日常聊天模型和长文写作模型分开。

## 指令

```text
{唤醒词}wr{可选字数} {详细需求}
```

示例：

```text
/wr300 写一篇周记
/wr 写一篇周记
/wr1000 续写
```

唤醒词会读取 AstrBot 当前配置，不固定为 `/`。不写字数时，模型会根据需求自由决定篇幅。

## 功能

- 在插件配置中下拉选择写作专用 provider。
- 写作时主动读取当前会话人设卡，并可选追加写作提示词。
- 模型只生成正文，标题行由插件硬拼接。
- 群聊中默认始终使用合并转发形式发送文章。
- 私聊中直接发送完整文本。
- 检测到续写类需求时，优先使用内存缓存中的最近一篇文章作为前文。
- 如果缓存没有命中，会先通过 `get_msg` 读取被引用消息；如果引用里是合并转发，再继续用 `get_forward_msg` 拆出正文。

## 输出格式

群聊优先读取用户群名片：

```text
——给【用户群名片】的文章——
{正文}
```

私聊使用昵称或 QQ 号兜底：

```text
——给【用户QQ名】的文章——
{正文}
```

## 配置

| 配置项 | 说明 |
| --- | --- |
| `writer_provider_id` | 写作专用模型提供商 |
| `writer_system_prompt` | 可选的追加写作提示词 |
| `min_words` | 允许请求的最小字数 |
| `max_words` | 允许请求的最大字数 |
| `always_forward_in_group` | 群聊中是否始终合并转发 |
